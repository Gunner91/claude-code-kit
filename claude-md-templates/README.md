# CLAUDE.md templates

Starter `CLAUDE.md` files for three common project types, plus path-scoped rules in `.claude/rules/` and a `CLAUDE.local.md` example.

| Folder | Stack |
|---|---|
| `web-app/` | Next.js / React + Node, with an API rule scoped to `app/api/**` |
| `python-api/` | FastAPI + PostgreSQL + Alembic |
| `php-site/` | Plain PHP multilingual site, with a content rule |

Copy one into your project root, replace the placeholders and keep it under ~200 lines.
Full guide: https://kriatiz.com/en/blog/claude-code-claude-md/ (EN) · https://kriatiz.com/ua/blog/claude-code-claude-md/ (UA) · https://kriatiz.com/blog/claude-code-claude-md/ (RU)
